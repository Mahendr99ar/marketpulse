# Labels

Hand labels live here and are committed to Git. They are the answer key for every evaluation.

- `to_label_real.csv`: written by `cli label-sheet`. Copy it, fill `notable` with 1 or 0, save as `notable_moves.csv`.
- `notable_moves.csv`: columns `date, instrument, change, notable, note`.
- `retrieval_labels.csv`: columns `date, instrument, relevant_url`. One row per relevant article.
